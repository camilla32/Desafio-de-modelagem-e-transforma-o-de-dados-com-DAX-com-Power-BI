# Desafio de modelagem e transformação de dados com DAX com Power-BI

Sobre o projeto
------

O projeto consiste na criação de tabela fato e dimensão a partir de dados de exemplos contidos no Power Bi da tabela  Financias

Etapas
----

- Duplicação da tabela financias.
- criação da tabela fato e dimensão.
- criação do esquema estrela
- criação da tabela calendario com a DAX calendar().
